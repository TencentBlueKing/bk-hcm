# PRD — CLB 独占集群购买、单据与详情适配

## 1. 背景与目标

业务用户需要在购买腾讯云公网负载均衡时选择已分配给当前业务的独占集群；运营人员需要在申请单和 CLB 详情中核对申请参数及资源实际落地的独占集群信息。

本迭代覆盖购买、申请单详情和 CLB 资源详情三个场景，确保独占集群选择、共享带宽包出口约束和详情展示形成完整闭环。

## 2. 范围

### 2.1 本迭代包含

1. 购买负载均衡时支持独占型规格及四层、七层独占集群选择。
2. 共享带宽包按已启用独占集群的网络出口过滤。
3. 负载均衡申请单详情展示申请时的独占集群参数。
4. CLB 资源详情展示实例规格和实际独占集群信息。

### 2.2 本迭代不包含

1. 独占集群管理页面。
2. CLB 列表的实例规格列及筛选。
3. 监听器、安全组等其它详情页签调整。
4. 后端接口与数据模型开发。

## 4. 用户故事

### US-01 购买独占型负载均衡

作为业务用户，我希望在购买公网负载均衡时选择当前业务可用的四层或七层独占集群，以便实例按指定或随机方式落到符合业务约束的独占集群。

### US-02 核对申请单参数

作为运营人员，我希望在负载均衡申请单详情中查看申请时选择的独占集群参数，以便核对申请内容。

### US-03 核对资源实际配置

作为运营人员，我希望在 CLB 资源详情中查看实例规格和实际独占集群信息，以便确认资源实际落地情况。

## 5. 功能需求

### 5.1 独占型规格可用性

1. 负载均衡规格类型顺序为：共享型、性能容量型、独占型。
2. 独占型仅支持业务视角购买腾讯云公网负载均衡。
3. 只有当前业务存在符合地域、可用区和运营商条件的可用独占集群时，才允许选择独占型。
4. 独占集群查询失败时应提示错误，不得提交独占型申请。
5. 切换账号、地域、可用区、运营商或网络类型后，已不再适用的独占集群选择必须失效。
6. 运营商类型仅支持三网直连（移动 CMCC、联通 CUCC、电信 CTCC）时可选择独占型；BGP 等其它运营商不支持选择独占型，也不发起独占集群查询。

### 5.2 四层与七层启用交互

1. 四层和七层选择器前分别提供启用复选框，默认均未勾选。
2. 未勾选时，对应选择器置灰；该层不参与必填校验、申请提交、空闲 IP 查询或共享带宽包出口计算。
3. 取消勾选时保留该层已有选择，但保留值暂不生效。
4. 重新勾选后，保留值立即恢复生效，并立即参与校验、提交和共享带宽包联动。
5. 账号、地域、可用区或运营商等上游条件变化时，即使该层未勾选，也应清除已失效的保留值。
6. 独占型至少启用四层或七层之一；两层均未启用时不得保存。
7. 四层和七层可以同时启用。

### 5.3 四层独占集群

1. 启用四层后，四层集群标签必选。
2. 集群标签只展示当前业务已分配且符合公网、地域和运营商条件的四层独占集群。
3. 标签下的具体集群只展示符合当前可用区的集群。
4. 用户可选择随机集群或某个具体集群：
   - 随机集群表示在标签下符合条件的集群中随机分配。
   - 具体集群表示申请落到用户指定的集群。
5. 选择具体集群后，用户可选择随机 IP 或该集群当前可用的某个空闲 IP。
6. 具体集群没有空闲 IP 时，该集群不可作为有效选择，并应向用户说明不可用原因。
7. 切换四层标签或具体集群后，原 IP 选择失效。

### 5.4 七层独占集群

1. 启用七层后，七层集群标签必选。
2. 七层标签只展示当前业务已分配且符合条件的七层独占集群。
3. 七层不提供具体集群名称和 IP 选择。

### 5.5 共享带宽包出口约束

1. 共享带宽包必须与当前已启用独占集群的网络出口一致。
2. 只启用四层时，按四层具体集群或四层标签下候选集群的有效出口过滤。
3. 只启用七层时，按与七层标签对应的有效出口过滤。
4. 四层和七层同时启用时，只保留同时满足两层出口约束的共享带宽包。
5. 带宽包候选必须覆盖全部符合基础查询条件的数据，不能因接口分页遗漏后续页中的匹配项。
6. 四层/七层勾选状态、标签、集群或有效出口发生变化时，已选共享带宽包立即失效，用户必须重新选择。
7. 没有匹配出口的共享带宽包时，候选列表为空；选择共享带宽包计费的申请不得提交。
8. 带宽包查询失败时应提示错误，选择共享带宽包计费的申请不得提交。

### 5.6 配置清单

1. 四层或七层任一启用时，实例规格显示为“独占型”。
2. 未选择独占型时，继续按现有共享型或性能容量型规则展示。
3. 未勾选层中保留的历史值不得影响配置清单或最终提交结果。

### 5.7 申请单详情

1. 在单据管理的负载均衡申请单详情中，独占型申请在“负载均衡规格类型”之后展示独占集群参数区块。
2. 参数区块展示：四层集群标签、四层集群名称、四层集群 IP、七层集群标签。
3. 详情以申请时参数为准，不使用交付后的资源实际配置替换申请参数。
4. 随机分配、未涉及或数据缺失的字段展示为空值。
5. 共享型和性能容量型申请隐藏整个独占集群参数区块。
6. 任一字段缺失时，页面仍应正常展示其它内容。

### 5.8 CLB 资源详情

1. 在 CLB 详情“配置信息”末尾展示实例规格。
2. 实例规格按以下优先级展示：独占型、性能容量型、共享型。
3. 独占型实例展示四层集群标签、四层集群名称、四层集群 IP和七层集群标签。
4. 共享型和性能容量型实例不展开独占集群字段。
5. 某一层未涉及或字段缺失时显示空值，不得阻断详情页加载。

## 6. 验收标准

### AC-01 独占型入口

- Given 当前业务存在符合条件的独占集群
- When 用户购买公网负载均衡
- Then 规格类型中可选择位于性能容量型之后的独占型

### AC-02 不可用业务

- Given 当前业务没有符合条件的独占集群
- When 用户打开购买表单
- Then 独占型不可选，且不能构造独占型申请

### AC-03 分层启用

- Given 用户选择独占型
- When 四层或七层未勾选
- Then 对应控件置灰、保留值不生效，且两层至少启用一层才能保存

### AC-04 恢复保留值

- Given 某层已有选择后被取消勾选
- When 用户重新勾选该层且上游条件未变化
- Then 原选择立即恢复生效，并重新触发校验和带宽包联动

### AC-05 四层指定集群与 IP

- Given 用户启用四层并选择具体集群
- When 集群存在空闲 IP
- Then 用户可选择随机 IP 或具体空闲 IP

### AC-06 四层无空闲 IP

- Given 用户选择的具体四层集群没有空闲 IP
- When 空闲 IP 查询完成
- Then 该集群不能作为有效选择，页面给出提示且不得提交

### AC-07 出口过滤

- Given 用户启用四层、七层或同时启用两层，并选择共享带宽包计费
- When 带宽包数据加载完成
- Then 仅展示满足当前有效出口约束的全部带宽包；两层同时启用时采用出口交集

### AC-08 联动失效

- Given 用户已选择共享带宽包
- When 任一层勾选状态、标签、集群或有效出口变化
- Then 原带宽包立即清空并要求重新选择

### AC-09 申请单详情

- Given 独占型申请单
- When 运营人员打开申请单详情
- Then 规格类型之后展示申请时的四层和七层参数；缺失值为空且页面正常

### AC-10 非独占申请单

- Given 共享型或性能容量型申请单
- When 运营人员打开申请单详情
- Then 不展示独占集群参数区块

### AC-11 CLB 资源详情

- Given 独占型 CLB
- When 运营人员打开配置信息
- Then 展示实例规格为独占型以及实际四层/七层字段；缺失字段为空

### AC-12 非独占资源详情

- Given 共享型或性能容量型 CLB
- When 运营人员打开配置信息
- Then 正确展示实例规格且不展开独占集群字段

### AC-13 运营商限制

- Given 用户购买公网负载均衡并选择运营商类型
- When 运营商为移动（CMCC）、联通（CUCC）或电信（CTCC），且该条件下存在可用独占集群
- Then 规格类型中可选择独占型
- When 运营商为 BGP 或其它非三网类型
- Then 不展示独占型；已选独占型时自动回退为共享型，且不携带任何独占集群参数提交

## 7. 依赖与约束

1. 购买能力弱依赖独占集群管理页面完成业务与独占集群的分配配置。
2. 购买、申请单和资源详情依赖后端提供稳定的独占集群查询、申请和详情数据。
3. 本阶段只定义产品行为；接口字段、数据映射、请求竞态处理和代码结构在后续 API、Design 与 Coding 阶段确定。
