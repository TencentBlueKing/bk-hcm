## 2. 信息架构 / 布局

### 2.1 购买表单

1. 沿用现有购买负载均衡侧滑表单及“配置信息 / 购买信息”卡片。
2. “负载均衡规格类型”下拉增加独占型，顺序为共享型、性能容量型、独占型。
3. 选择独占型后，在规格区域展开独占集群配置：
   - 四层行：启用复选框、四层集群标签、集群名称、IP分配。
   - 七层行：启用复选框、七层集群标签。
4. 复选框与层级名称位于选择器左侧；同一层的选择器保持横向排列，沿用表单既有宽度与间距。
5. “共享带宽包”仍位于购买信息卡片的网络计费模式之后，不移动现有带宽上限和购买数量布局。
6. 配置清单沿用现有表格，仅调整规格字段的显示语义。

### 2.2 申请单详情

1. 沿用“基本信息 / 参数信息”双列网格。
2. 独占型申请在“负载均衡规格类型”之后连续插入四层标签、四层名称、四层 IP、七层标签。
3. 共享型和性能容量型不渲染上述字段，保持现有布局顺序。

### 2.3 CLB 资源详情

1. 沿用资源列表详情的“资源信息 / 配置信息 / 跨域配置”结构。
2. 在配置信息末尾增加实例规格。
3. 独占型在实例规格之后追加四层标签、名称、IP及七层标签；非独占型不追加。
4. 不改变左侧资源列表、顶部页签和其它详情区域。

## 3. 关键交互

### 3.1 独占型可见与切换

1. 独占型只在业务视角、公网、运营商为三网直连（CMCC / CUCC / CTCC）且存在可用独占集群时可选；运营商为 BGP 等其它类型时不展示「独占型」，已选时回退共享型。
2. 选择独占型后展示四层、七层配置；默认两个复选框均未勾选。
3. 切回共享型或性能容量型时隐藏独占配置，并使独占值不参与本次保存。

### 3.2 四层与七层复选框

1. 勾选后，对应层选择器立即可编辑并参与校验、提交和带宽包联动。
2. 取消勾选后，对应控件置灰但保留已选值；该层立即退出校验、提交和出口计算。
3. 在上游条件不变时重新勾选，保留值立即恢复生效。
4. 账号、地域、可用区或 ISP 变化时，清除已不适用的保留值。
5. 保存独占型配置时至少勾选一层；两层都未勾选时在独占配置区域提示校验错误。

### 3.3 四层选择

1. 勾选四层后先选标签，再选随机分配或某个具体集群。
2. 选择随机集群时，IP仅显示随机分配。
3. 选择具体集群后加载空闲 IP，可选随机分配或具体 IP。
4. 具体集群无空闲 IP时，提示该集群不可用，不保留为有效选择。
5. 切换标签或具体集群后，原 IP 选择立即失效。

### 3.4 七层选择

1. 勾选七层后只选择七层标签。
2. 不展示七层具体集群和 IP 控件。
3. 四层和七层可以同时启用。

### 3.5 共享带宽包

1. 只根据当前已勾选层计算有效出口；未勾选层即使保留值也不参与。
2. 四层和七层同时启用时使用出口交集。
3. 勾选状态、标签、具体集群或出口变化后，已选带宽包立即清空并重新加载候选。
4. 加载期间选择器显示 loading；无匹配项时显示空列表。
5. 共享带宽包计费模式下，没有有效候选或未重新选择带宽包时不能保存。

## 4. 状态流转

| 当前状态 | 触发 | 下一状态 / 结果 |
|----------|------|-----------------|
| 非独占规格 | 选择独占型 | 展开两层配置，复选框默认未勾选 |
| 层未启用 | 勾选复选框 | 控件启用，保留值立即生效并触发联动 |
| 层已启用 | 取消复选框 | 控件置灰、值保留、该层联动立即失效 |
| 已选具体四层集群 | 空闲 IP 加载成功且非空 | IP 控件可选随机或具体 IP |
| 已选具体四层集群 | 空闲 IP 为空 | 提示不可用，该集群不能成为有效选择 |
| 已有带宽包 | 有效出口变化 | 清空带宽包，重新加载和过滤候选 |
| 独占配置有效 | 保存 | 写入配置清单并显示独占型 |

## 5. 异常 / 边界态

| 场景 | 展示 |
|------|------|
| 独占集群查询中 | 相关选择器 loading，禁止重复操作 |
| 独占集群查询失败 | 错误提示；独占型配置不可保存 |
| 标签下无集群 | 具体集群为空；该层不能形成有效选择 |
| 具体集群无空闲 IP | 提示不可用；不保留有效集群选择 |
| 带宽包全量加载中 | 共享带宽包选择器 loading |
| 出口交集为空 / 无匹配带宽包 | 空列表；共享带宽包计费下禁止保存 |
| 请求切换后旧响应返回 | 旧响应不更新当前表单状态 |
| 申请单或 CLB 详情字段缺失 | 对应值按项目规范显示空值，其它内容正常展示 |
| 文本过长 | 沿用现有 Select 与详情字段的溢出展示方式 |

## 6. 与 PRD 差异（如有）

| 项 | PRD | 稿面/确认结论 |
|----|-----|---------------|
| 取消勾选 | 保留值但不生效 | 原型未标注，采用用户明确确认口径 |
| 重新勾选 | 保留值立即恢复联动 | 原型未标注，采用用户明确确认口径 |
| 带宽包出口 | 使用已启用层的出口交集 | 稿面仅展示控件，采用用户明确确认口径 |
| 申请单随机值 | 随机或缺失字段展示为空 | 稿面为示例数据，采用 PRD 口径 |
