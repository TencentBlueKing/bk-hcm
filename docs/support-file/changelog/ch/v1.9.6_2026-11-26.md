**V1.9.6 版本更新日志**

# 新增
- [新增] 子网-增加独立的子网同步入口；
- [新增] 负载均衡-配置检索支持复制 RS IP；
- [新增] 资源同步-支持屏蔽地域；
- [新增] 负载均衡-购买支持按 BGP 与限速 CAP 查询独占集群；
- [新增] 资源-独占集群列表运营商增加混合运营商查询条件；
- [新增] 监听器删除后可从提示跳转任务详情，并禁用该行；

# 优化
- [优化] 菜单整合二期：资源接入下线；
- [优化] 主机开关机与回收分开预鉴权，并修正下拉菜单横排；
- [优化] 负载均衡-实例规格中文名等实例参数改为前端调接口；
- [优化] 刷新后按账号详情补回资源列表的云厂商条件；
- [优化] 负载均衡-创建后先确认云上可见再同步，并补全备可用区；

# 修复
- [修复] 被禁用的云账号在只剩一个时仍被自动选中；
- [修复] 负载均衡详情页 tab 路由参数未隔离；
- [修复] 负载均衡-目标组健康检查请求参数偶现遗漏；
- [修复] 去掉同步独占集群列表 cloud_ids 的数量上限；
- [修复] 为 CVM created_at 建索引，解决列举 CVM 时内存溢出；
- [修复] 认证过滤改用解码后的请求路径做匹配；
- [修复] 恢复腾讯云子网条件同步注册；
- [修复] 负载均衡批量更新按主键升序加锁，避免并发死锁；
- [修复] 切换负载均衡实例后安全组展开状态循环触发导致页面卡死；
