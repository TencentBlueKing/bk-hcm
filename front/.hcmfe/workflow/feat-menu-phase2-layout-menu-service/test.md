## 验证范围

- 功能边界: 旧壳 `views/home` 替换为 `app.vue` + `components/layout/*`；顶栏、侧栏、面包屑、业务选择器、页脚、状态页（404）、最小宽度、通知栏、退出登录。菜单项、地址、各页面包屑与现网逐项一致。
- 有意变化（按 PR #1897）: 面包屑默认显示（审计后逐页与现网一致）、顶栏链接样式、页面最小宽度 1366px、未知地址进 404、403 页顶栏不再高亮「资源接入」、退出登录回跳地址完整保留。
- 不在范围: 视图权限体系（②）、资源纳管与资源运营新结构（③～⑦）、菜单收藏 / 分组折叠 / `/business/:bizId`（收尾单）。资源运营仍为一期结构，资源接入仍为旧形态。

## 测试环境

- 前端入口: `<测试环境地址，由执行人确认>`，以下地址均为 hash 路由片段（`#/...`）
- 测试账号: `<test_account>`（全权限）、`<test_account_limited>`（无一级账号 / 云账单管理 / 权限策略库权限）
- 数据准备:
  - 至少 2 个有权限的业务，其中一个有主机数据
  - 资源选型开关 `ENABLE_CLOUD_SELECTION`、账单开关 `ENABLE_ACCOUNT_BILL` 可在测试环境切换（AC-002 用）
  - 通知栏开关 `ENABLE_NOTICE` 开启且后台有一条跑马灯公告（P0-12 用；无条件可 Skipped）
  - 改造前的页面截图或另一套未升级环境，用于逐项对比
