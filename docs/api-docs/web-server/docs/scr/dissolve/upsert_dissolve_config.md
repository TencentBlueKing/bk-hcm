### 描述

- 该接口提供版本：v1.8.7+。
- 该接口所需权限：平台管理-机房裁撤。
- 该接口功能描述：添加或更新裁撤配置。

### URL

PUT /api/v1/woa/dissolve/config/upsert

### 输入参数

| 参数名称            | 参数类型    | 必选 | 描述                                         |
|-----------------|---------|----|--------------------------------------------|
| host_apply_time | string  | 否  | 统计机房裁撤主机的开始时间                              |
| approval_limit  | string  | 否  | 主机裁撤项目申请自动审批配置，超过比例后，则申请单需要管理员人工审批，范围0-100 |

### 调用示例

#### 请求参数示例

```json
{
   "host_apply_time": "2024-09-01T12:00:00Z",
   "approval_limit": 100
}

```

### 响应示例

#### 获取详细信息返回结果示例

```json
{
  "code": 0,
  "message": "ok",
  "data": null
}
```

### 响应参数说明

| 参数名称  | 参数类型   | 描述   |
|---------|-----------|--------|
| code    | int       | 状态码  |
| message | string    | 请求信息 |
| data    | object    | 响应数据 |
