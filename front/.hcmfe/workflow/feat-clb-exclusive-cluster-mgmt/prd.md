## 用户故事

作为平台管理员，我想在「资源接入 → 负载均衡」下通过「独占集群」入口查看集群并分配业务，以便管控哪些业务可以使用独占资源。

## 功能需求

### 入口

1. 在资源接入-负载均衡增加与安全组页「安全组 / 参数模板」同形态的子入口：`负载均衡`、`独占集群`。
2. 原负载均衡列表与操作收入「负载均衡」入口，进入该页时默认选中「负载均衡」。
3. 「独占集群」展示集群实体列表，并与左侧云账号树联动。
4. 不做容量管理菜单；第 1 轮「容量管理」入口口径作废。

### 列表

独占集群列表列：

- 集群 ID
- 集群名称
- 类型（TGW / STGW）
- 集群标签
- 可用区
- 运营商
- 最大连接数（STGW 无值时展示 `--`）
- 集群内实例数
- 业务（未分配展示 `--`）
- 操作

### 筛选

支持按以下条件筛选，仅展示命中行：

- 业务
- 集群标签
- 类型
- 可用区
- 运营商
- 集群 ID
- 集群名称

### 分配

1. 工具栏仅提供「批量分配」。
2. 未分配行显示「分配」；已分配行操作列为 `--`，不可再勾选、不可再分配。
3. 分配弹窗对齐证书分配：目标业务单选。
4. 分配成功后，业务列展示目标业务名称，操作变为 `--`。
5. 分配失败时弹窗提示，列表不乐观更新。
6. 不提供启用/禁用；不支持再次分配。

### 异常

列表加载失败时展示错误态并可重试，不白屏。列表数据未就绪时允许先用占位数据完成页面联调，不阻塞本页交付口径。

## 验收标准

- [ ] **AC-001**：打开资源接入-负载均衡时，可见「负载均衡」和「独占集群」两个子入口；原 CLB 列表在「负载均衡」入口下。
- [ ] **AC-002**：对未分配集群执行单条或批量分配到业务 A 后，业务列显示业务 A 名称，操作变为 `--`，不可再分配。
- [ ] **AC-003**：已分配集群的复选框禁用，不能进入批量分配集合。
- [ ] **AC-004**：使用业务、类型、集群标签等筛选后，仅展示命中行。
- [ ] **AC-005**：列表加载失败时展示错误并可重试，不白屏。
