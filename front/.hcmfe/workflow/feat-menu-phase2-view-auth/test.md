# feat-menu-phase2-view-auth 测试清单

> 工作流: `feat-menu-phase2-view-auth`
> 关联文档: [需求](../../../../docs/reqs/二期视图权限体系.md)（AC-001～AC-009、AC-P01、AC-S01、AC-S02）/ [Coding](./coding.md)

## 验证范围

- 功能边界: 页面查看权限改为「路由声明 + 启动预鉴权 + 守卫判定 + 框架内无权限页」；业务资源的三种业务状态页；侧栏按视图权限显隐；接口无权限（HTTP 403 / 2030403）统一弹申请弹窗；删除整页无权限与旧全局权限弹窗；主机操作列改用按钮级鉴权；业务选择器在业务无权限 / 不存在时不查收藏。
- 拦截范围: 与现网逐页一致（R-004），唯一有意差异是裸地址 `#/resource`（落到账号列表，无账号查看权限时也拦截，已确认接受）。
- 不在范围: 各页面按钮级鉴权迁移（主机操作列除外）、`/business/:bizId`、资源运营新结构（③～⑦）。

## 测试环境

- 前端入口: `<测试环境地址，由执行人确认>`，以下地址均为 hash 路由片段（`#/...`）
- 测试账号:
  - `<test_account>`：全部相关权限
  - `<test_account_limited>`：无一级账号、二级账号、云账单管理、权限策略库、账号查看、回收站查看、方案创建 / 查看权限；有至少一个业务的访问权限，但对 `<unauthed_biz_id>` 无权限
  - `<test_account_nobiz>`：无任何业务访问权限（可选，P0-07 用）
- 数据准备:
  - `<unauthed_biz_id>`：存在但 `<test_account_limited>` 无权限的业务 ID；`<missing_biz_id>`：不存在的业务 ID（如 999999999）
  - 浏览器 DevTools 可屏蔽请求（Network → Block request URL），P1-03 用
