### 描述

- 该接口提供版本：v9.9.9。
- 该接口所需权限：平台-全局配置。
- 该接口功能描述：给私有镜像配置业务归属标签（本地补充 bk_biz_id）。

### URL

PUT /api/v1/cloud/images/{image_id}/biz_tag

#### 路径参数说明

| 参数名称     | 参数类型   | 必选 | 描述              |
|----------|--------|----|-----------------|
| image_id | string | 是  | 镜像 ID（系统内部 ID） |

### 输入参数

| 参数名称      | 参数类型  | 必选 | 描述                                      |
|-----------|-------|----|-----------------------------------------|
| bk_biz_id | int64 | 是  | 业务 ID，-1 表示取消业务绑定（未分配），正整数表示绑定到具体业务 |

### 调用示例

#### 请求参数示例（绑定到业务）

```json
{
  "bk_biz_id": 100
}
```

#### 请求参数示例（取消业务绑定）

```json
{
  "bk_biz_id": -1
}
```

### 响应示例

#### 成功返回结果示例

```json
{
  "code": 0,
  "message": ""
}
```

#### 镜像不存在返回结果示例

```json
{
  "code": 2000003,
  "message": "image id (xxx) not found"
}
```

#### 非私有镜像返回结果示例

```json
{
  "code": 2000001,
  "message": "only private image can set bk_biz_id, current image type is public"
}
```

### 响应参数说明

| 参数名称    | 参数类型   | 描述   |
|---------|--------|------|
| code    | int    | 状态码  |
| message | string | 请求信息 |
