> 工作流: `feat-menu-phase1-rename-bill-group`
> 关联文档: PRD / Coding（本迭代无 Design / API）

## 验证范围

- 功能边界：两个一级菜单更名（资源管理 → 业务资源、账号管理 → 资源运营）；「资源运营」侧栏改为一个二级分组「云账单管理」下挂「云账号管理」「云账单管理」两项；bill 路由迁到去中心化模式（按路由名跳转与重定向）；资源运营侧栏改由 menu-service 雏形供数。
- 不在范围：「业务资源」下的分组与菜单项（只改一级名称）；服务请求 / 资源接入 / 资源选型的侧栏；新增父单列出的第三个账单类菜单项；页面内容本身。

## 预验证（已完成，不必重复手点）

编码阶段已用临时脚本在**新旧两份路由表**上跑真实 vue-router 对比，以下结论已成立：

- 9 条旧地址 + 1 条带 query 的地址：新旧落点完全一致，高亮的是同一个菜单项。
- 代码里 11 种跳转（顶栏、侧栏两项、三个页签、汇总页「操作记录」、两个录入页按路由名 / 按路径）全部落到期望地址。
- 按路由名的两处重定向落点不变，重定向后 query 保留。
- 停留在「操作记录」子页时，「账单汇总」路由仍在匹配链中（页签高亮的前提）。
- 侧栏数据：一个分组「云账单管理」、两项，标题 / 图标 / 高亮键 / 权限键正确，子项不带页签子路由。

本清单聚焦脚本覆盖不到的部分：**实际渲染、交互、权限与开关**。
