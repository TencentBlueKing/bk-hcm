## 缺陷与修复（D-01 — 已在 coding 阶段修复并复验）

**D-01 独占型配置无法保存（P0 缺陷，曾阻塞单据 1 的全部提交路径）**

- 现象：选好独占型并完整配置四层（标签 + 随机集群 + 随机 IP）后点击「保存」，「独占集群」字段报错「独占集群不能为空」，侧滑不关闭、配置清单不新增；即使除独占集群外的必填项全部填好，唯一的报错仍是这一条。
- 根因（源码定位）：`src/views/service/service-apply/clb/hooks/useRenderForm.tsx` 中「独占集群」`FormItem` 同时设置了 `required: true` 与 `property: 'exclusive_config'`，而 `exclusive_config` 并不是 `ApplyClbModel` 上的字段，bkui 的表单必填规则始终判定为空并给出默认文案，自定义校验器的文案「请至少启用并完整配置一个独占集群」永远不生效。
- 影响：`P0-02`~`P0-05`（四层/七层/合并/具体集群的提交参数）全部无法到达提交，`P1-01` 的实际提示文案与设计意图不一致。
- 修复（coding 阶段）：移除该 `FormItem` 的 `required: true`；把自定义校验迁到 `FormItem` 的项级 `rules`（BKUI `FormItem` 支持 `Array<IFormItemRule>`，已核对组件文档）；`ClbFormItemOption` 增加可选 `rules` 并透传。详见 `coding.md` 的「D-01 修复记录」。
- 视觉副作用：该字段不再显示必填星号（BKUI 无独立控制星号的属性）。如需保留星号，可让 `exclusive_config` 落到真实模型字段，请需求方确认。
- 复验：修复后重跑同一 spec，**22 passed / 0 failed**；此前 Blocked 的 `P0-02`~`P0-05`、`P1-02`、`P1-08`、`P1-09` 全部补齐并通过。
- 原始失败证据（保留追溯）：`e2e/test-results/...四层随机集群可保存并提交标签下全部候选集群与空-VIP/test-failed-1.png`。
