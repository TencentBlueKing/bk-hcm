### 描述

- 该接口提供版本：v9.9.9。
- 该接口所需权限：自研云管理-交付分析。
- 该接口功能描述：新增指定月份的配置。

### URL

POST /api/v1/woa/task/config/create/apply/order/statistics

### 输入参数

| 参数名称       | 参数类型   | 必选 | 描述                                    |
|------------|--------|----|---------------------------------------|
| stat_month | string | 是  | 年月，格式：YYYY-MM，如 "2025-01"               |
| configs    | array  | 是  | 配置数组，至少包含一个配置项，支持批量添加多条配置            |

#### configs[n] 配置项参数

| 参数名称          | 参数类型   | 必选 | 描述                                                             |
|---------------|--------|----|----------------------------------------------------------------|
| bk_biz_id     | int    | 是  | 业务ID，必填字段，必须大于0                                                |
| sub_order_ids | array  | 否  | 子单号列表，最多支持100个子单号。子单号和时间段必须二选一填写                               |
| start_at      | string | 否  | 开始时间，格式：YYYY-MM-DD。如果设置了 start_at，必须同时设置 end_at,子单号和时间段必须二选一填写 |
| end_at        | string | 否  | 结束时间，格式：YYYY-MM-DD。如果设置了 end_at，必须同时设置 start_at,子单号和时间段必须二选一填写 |
| memo          | string | 是  | 备注，最大255字符，必填字段                                                |

### 调用示例

#### 单条配置示例（使用子单号）

```json
{
  "stat_month": "2025-01",
  "configs": [
    {
      "bk_biz_id": 213,
      "sub_order_ids": ["000001", "000002", "000003"],
      "memo": "业务213的1月份统计配置"
    }
  ]
}
```

#### 批量配置示例（多条数据）

```json
{
  "stat_month": "2025-01",
  "configs": [
    {
      "bk_biz_id": 213,
      "sub_order_ids": ["000001", "000002"],
      "memo": "业务213的排除配置"
    },
    {
      "bk_biz_id": 214,
      "start_at": "2025-01-01",
      "end_at": "2025-01-15",
      "memo": "业务214的时间范围排除配置"
    },
    {
      "bk_biz_id": 215,
      "sub_order_ids": ["000003"],
      "start_at": "2025-01-10",
      "end_at": "2025-01-20",
      "memo": "业务215同时使用子单号和时间范围"
    }
  ]
}
```

### 响应示例

#### 返回结果示例

```json
{
  "result": true,
  "code": 0,
  "message": "success",
  "data": {
    "ids": ["0000000b", "0000000c", "0000000d"]
  }
}
```

### 响应参数说明

| 参数名称    | 参数类型   | 描述                         |
|---------|--------|----------------------------|
| result  | bool   | 请求成功与否。true:请求成功；false请求失败 |
| code    | int    | 错误编码。 0表示success，>0表示失败错误  |
| message | string | 请求失败返回的错误信息                |
| data	   | object | 响应数据                       |

#### data

| 参数名称 | 参数类型   | 描述                      |
|------|--------|-------------------------|
| ids  | array  | 配置ID数组，按创建顺序返回，数量与请求的configs数量一致 |
