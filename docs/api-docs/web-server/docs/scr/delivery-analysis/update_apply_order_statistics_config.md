### 描述

- 该接口提供版本：v9.9.9。
- 该接口所需权限：自研云管理-交付分析。
- 该接口功能描述：编辑指定月份的配置，支持全量覆盖更新。支持多业务配置，每个配置需指定业务ID。

### URL

PUT /api/v1/woa/task/config/update/apply/order/statistics

### 输入参数

| 参数名称    | 参数类型   | 必选 | 描述                              |
|---------|--------|----|---------------------------------|
| stat_month | string | 是  | 年月，格式：YYYY-MM，如 "2025-01"       |
| configs | array  | 是  | 配置列表，全量覆盖更新。如果为空数组，则删除该月份下的所有配置 |

#### configs[n]

| 参数名称          | 参数类型   | 必选 | 描述                                              |
|---------------|--------|----|-------------------------------------------------|
| bk_biz_id     | int    | 是  | 业务ID                                            |
| sub_order_ids | array  | 否  | 子单号列表，最多支持100个子单号。子单号和时间段必须二选一填写                |
| start_at      | string | 否  | 开始时间，格式：YYYY-MM-DD。子单号和时间段必须二选一填写 |
| end_at        | string | 否  | 结束时间，格式：YYYY-MM-DD。子单号和时间段必须二选一填写 |
| memo          | string | 是  | 备注，最大255字符，必填字段                                 |

### 调用示例

#### 获取详细信息请求参数示例

```json
{
  "year_month": "2025-01",
  "configs": [
    {
      "bk_biz_id": 213,
      "start_at": "2025-01-01",
      "end_at": "2025-01-31",
      "sub_order_ids": ["000001", "000002", "000003"],
      "memo": "1月份统计配置1"
    },
    {
      "bk_biz_id": 213,
      "start_at": "2025-01-01",
      "end_at": "2025-01-31",
      "sub_order_ids": ["000001", "000002", "000003"],
      "memo": "1月份统计配置2"
    },
    {
      "bk_biz_id": 214,
      "start_at": "2025-01-01",
      "end_at": "2025-01-31",
      "sub_order_ids": ["000004"],
      "memo": "1月份统计配置3"
    }
  ]
}
```

#### 清空配置示例

```json
{
  "stat_month": "2025-01",
  "configs": []
}
```

### 响应示例

#### 获取详细信息返回结果示例

```json
{
  "result": true,
  "code": 0,
  "message": "success",
  "data": null
}
```

### 响应参数说明

| 参数名称    | 参数类型   | 描述                         |
|---------|--------|----------------------------|
| result  | bool   | 请求成功与否。true:请求成功；false请求失败 |
| code    | int    | 错误编码。 0表示success，>0表示失败错误  |
| message | string | 请求失败返回的错误信息                |
| data	   | object | 响应数据，成功时为null              |
