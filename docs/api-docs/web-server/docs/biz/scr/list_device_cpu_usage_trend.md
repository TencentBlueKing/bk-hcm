### 描述

- 该接口提供版本：v1.8.7.10+。
- 该接口所需权限：业务访问。
- 该接口功能描述：查询设备CPU利用率趋势信息。

### URL

POST /api/v1/woa/bizs/{bk_biz_id}/device/cpu_usage/trend

### 输入参数

| 参数名称             | 参数类型   | 必选 | 描述                                                |
|------------------|--------|----|---------------------------------------------------|
| time_granularity | string | 是  | 日期时间粒度，枚举值：day(每天)、week(周日)、month(月末)             |
| date_range       | object | 是  | 要查询时间范围。当粒度为day时，不能超过90天；当粒度为week或month时，不能超过25个月 |

#### date_range

| 参数名称  | 参数类型   | 必选 | 描述                            |
|-------|--------|----|-------------------------------|
| start | string | 是  | 起始时间，格式为"年-月-日"，如"2023-06-01" |
| end   | string | 是  | 结束时间，不能晚于当前日期，格式同 start       |

### 调用示例

#### 获取详细信息请求参数示例

```json
{
  "time_granularity": "month",
  "date_range": {
    "start": "2025-08-01",
    "end": "2025-11-01"
  }
}
```

### 响应示例

#### 获取详细信息返回结果示例

```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "date": "2025-11-25",
      "cpu_usage": 31.01
    },
    {
      "date": "2025-11-26",
      "cpu_usage": 32.15
    }
  ]
}
```

### 响应参数说明

| 参数名称    | 参数类型         | 描述                        |
|---------|--------------|---------------------------|
| code    | int          | 错误编码。 0表示success，>0表示失败错误 |
| message | string       | 请求失败返回的错误信息               |
| data    | object array | 响应数据                      |

#### data[n]

| 参数名称      | 参数类型   | 描述     |
|-----------|--------|--------|
| date      | string | 日期     |
| cpu_usage | float  | CPU利用率 |
