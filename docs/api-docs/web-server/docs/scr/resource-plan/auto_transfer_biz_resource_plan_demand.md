### 描述

- 该接口提供版本：v9.9.9+。
- 该接口所需权限：业务-资源预测操作。
- 该接口功能描述：根据业务ID和需求ID自动转移预测。该接口会将指定的预测需求自动转移到新的预测单据中，相同需求类型（demand_class）的需求会被合并到同一个单据中。

### URL

POST /api/v1/woa/bizs/{bk_biz_id}/plans/resources/demands/auto_transfer

### 输入参数

| 参数名称    | 参数类型         | 必选 | 描述                    |
|---------|--------------|----|-----------------------|
| bk_biz_id | int          | 是  | 业务ID（路径参数）            |
| demand_ids | string array | 是  | 预测需求ID列表，单次最多100个      |

### 调用示例

```json
{
  "demand_ids": [
    "0000001z",
    "0000002a",
    "0000003b"
  ]
}
```

### 响应示例

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "ticket_ids": [
      "00000001",
      "00000002"
    ]
  }
}
```

### 响应参数说明

| 参数名称    | 参数类型   | 描述                        |
|---------|--------|---------------------------|
| code    | int    | 错误编码。 0表示success，>0表示失败错误 |
| message | string | 请求失败返回的错误信息               |
| data    | object | 响应数据                      |

#### data

| 参数名称      | 参数类型         | 描述                                                          |
|----------|--------------|-------------------------------------------------------------|
| ticket_ids | string array | 生成的资源预测单据ID列表。注意：返回的单据数量可能少于传入的需求数量，因为相同需求类型（demand_class）的需求会被合并到同一个单据中 |
