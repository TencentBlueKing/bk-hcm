**V1.9.6 Release Notes**

# New Features
- [New] Subnet - Added an independent subnet sync entry
- [New] Load Balancer - Config search supports copying the RS IP
- [New] Resource Sync - Support disabling sync for a region
- [New] Load Balancer - Purchase supports querying exclusive clusters by BGP and rate-limit CAP
- [New] Resource - Exclusive cluster list supports the mixed-carrier filter
- [New] After a listener is deleted, the notice can open the task detail and the row is disabled

# Upgrade
- [Upgrade] Menu - Phase 2 removes the resource onboarding entry
- [Upgrade] Host power and recycle use separate pre-authorization, and the dropdown menu is laid out in a row
- [Upgrade] Load Balancer - Instance spec names and other instance parameters are loaded from the API
- [Upgrade] Refresh restores the resource list vendor filter from the account detail
- [Upgrade] Load Balancer - After creation, wait until the cloud resource is visible before syncing, and fill in the backup zone

# Bugfix
- [Bugfix] A disabled cloud account was still auto-selected when it was the only one
- [Bugfix] Load balancer detail tabs did not isolate route parameters
- [Bugfix] Target group health check requests occasionally omitted parameters
- [Bugfix] Removed the cloud_ids limit when syncing the exclusive cluster list
- [Bugfix] Indexed CVM created_at to fix out-of-memory errors when listing CVMs
- [Bugfix] Auth filter matches the decoded request path
- [Bugfix] Restored Tencent Cloud subnet conditional sync registration
- [Bugfix] Load balancer batch updates lock rows in primary-key order to avoid deadlocks
- [Bugfix] Switching load balancer instances retriggered security group expansion and froze the page
