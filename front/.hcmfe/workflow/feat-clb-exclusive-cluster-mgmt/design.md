## 2. UI 参照

- **现网入口形态**：资源接入 → 安全组（`/resource/resource` 安全组场景）。工具栏左侧为 `bk-radio-group` + `bk-radio-button` 切换「安全组 / 参数模板」（腾讯云）。本轮在负载均衡场景复用同一控件形态，文案改为「负载均衡」「独占集群」。
- **现网列表页**：资源接入 → 负载均衡（`src/views/resource/resource-manage/children/manage/load-balancer-manage.vue`）。进入该页默认停留在「负载均衡」入口，原 CLB 列表/操作不变。
- **现网分配**：资源接入下证书/安全组的「批量分配」是目标业务单选。CLB 页是批量组件 + 独立单条 dialog。独占集群不跟 CLB 拆两套：扩展批量组件，行内「分配」打开同一弹窗。
- **PRD 文字约束**：双入口、列表 10 列、7 类筛选、未分配可分配 / 已分配不可再分配、失败不乐观更新、列表错误可重试。

## 3. 关键交互与状态

### 3.1 入口

- 进入资源接入-负载均衡：默认「负载均衡」，展示现网 CLB 列表。
- 切换到「独占集群」：展示集群实体列表；切换时清空勾选。
- 与左侧云账号树联动：切换账号后列表按当前账号刷新（与现网 CLB 列表一致）。
- 不做容量管理菜单。

### 3.2 列表

| 列 | 展示规则 |
|----|----------|
| 集群 ID / 名称 / 类型 / 集群标签 / 可用区 / 运营商 | 原文案 |
| 最大连接数 | STGW 无值展示 `--` |
| 集群内实例数 | 数值 |
| 业务 | 未分配 `--` |
| 操作 | 未分配：「分配」；已分配：`--` |

### 3.3 筛选

支持：业务、集群标签、类型、可用区、运营商、集群 ID、集群名称。条件变更后仅展示命中行。

### 3.4 分配

- 工具栏仅「批量分配」；未勾选未分配行时按钮不可用（沿用现网批量分配禁用习惯）。
- 已分配行：复选框禁用，不进入批量集合。
- 单条「分配」调用批量组件 `open([row])`，与工具栏批量共用弹窗与接口；目标业务单选。
- 成功：业务列更新为业务名称，操作变 `--`，该行不可再分配。
- 失败：弹窗提示，列表保持原值。
- 不提供启用/禁用，不支持再次分配。

### 3.5 异常与占位

- 列表失败：错误态 + 重试，不白屏。
- 接口未就绪：允许占位数据联调，不改变上述交互口径。
