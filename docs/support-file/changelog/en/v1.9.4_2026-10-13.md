**V1.9.4 Release Notes**

# New Features
- [New] Load Balancer - Support exclusive cluster sync and business assignment
- [New] Load Balancer - Support querying, purchasing, and syncing exclusive load balancers, and display them in applications and details
- [New] Load Balancer - Instance spec filter includes performance capacity tiers
- [New] Certificate - Support assigning a certificate to a business
- [New] Application Detail - Added an API to view application details under a business
- [New] Tencent Cloud - Support conditional sync for subnets
- [New] Security Group - Clone supports selecting a target region

- [Upgrade] Load Balancer - Conditional sync shows asynchronous progress

- [Upgrade] Account Registration - Improved primary account onboarding guidance
