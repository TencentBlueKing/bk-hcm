# feat-clb-sync-task 测试清单

> 工作流: `feat-clb-sync-task`
> 关联文档: Coding（lite，无独立 PRD / Design / API）

## 验证范围

- 功能边界: CLB 条件同步改为异步任务；提交后按 `task_management_id` 提示并可跳到【任务管理-负载均衡】详情；任务类型「同步」可筛；操作详情列按协议；列表账号条件用 `json_overlaps`
- 不在范围: 百分比进度条；后端编排；改列表/详情分页协议；非 CLB 资源的默认同步成功文案（安全组仍走「已同步成功」）；同步任务重执行

## 测试环境

- 前端入口: `<对应业务的测试环境地址，由执行人在测试时确认；不要把具体域名写入仓库>`
- 测试账号: `<test_account>`（敏感信息用占位符，不写真实账号）
- 数据准备:
  - 业务视角：有 CLB 权限的业务，至少一个腾讯云账号、一个可同步地域；列表页与某条 CLB 详情（监听器页）均可打开
  - 资源视角：资源账号下有 CLB，可打开资源负载均衡列表
  - 任务管理：业务下【任务管理-负载均衡】可打开
  - 异常：同一账号+地域已有进行中的同步任务（测 `2000002`）；或拦截 `sync_by_cond` 回包构造 `code=2000002` / `task_management_id=""` / 其它 `code != 0`
  - 账号筛选：至少一条同步任务的 `account_ids` 含已知账号 id

## 用例清单

### P0 - 主流程（必测）

| ID | 场景 | 前置 | 操作 | 期望 | 回滚 |
|----|------|------|------|------|------|
| P0-01 | 业务列表提交条件同步 | 业务 CLB 列表；选腾讯云账号与地域 | 点「同步负载均衡」→ 填账号/地域 → 确定 | 弹窗关闭；Toast「同步任务已创建，可在【任务管理-负载均衡】查看进度」；网络回包有非空 `task_management_id` | 无 |
| P0-02 | Toast 跳到任务详情 | P0-01 成功且 Toast 未消失 | 点击 Toast 中「【任务管理-负载均衡】」 | 新窗口打开该任务详情（`resourceType=clb`，id 为回包任务 id，带当前 `bizs`） | 关新窗口 |
| P0-03 | 业务单条 CLB 同步 | 某条 CLB 监听器页 | 点「同步当前负载均衡」→ 账号/地域已预填且禁用 → 确定 | 同 P0-01/P0-02；请求 body 含该 CLB 的 `cloud_ids` | 无 |
| P0-04 | 资源视角同步 | 资源负载均衡列表 | 点「同步负载均衡」或行内同步 → 确定 | 同 P0-01；成功 Toast 可点进任务详情 | 无 |
| P0-05 | 任务列表展示「同步」 | 已有 `operations` 含 `sync_load_balancer` 的任务 | 打开【任务管理-负载均衡】 | 任务类型列显示「同步」，不是原始枚举值 | 无 |
| P0-06 | 按任务类型筛「同步」 | 列表中同时有同步与其它类型任务 | 任务类型选「同步」后查询 | 只留下同步任务 | 清空筛选 |
| P0-07 | 同步任务操作详情列 | 进入一条同步任务详情 | 看操作详情表 | 列为：开始时间、结束时间、类别（新增/修改/删除）、CLB ID（`cloud_lb_id`）、CLB VIP/域名、任务状态、失败原因；无 `cloud_clb_id` 等其它类型字段 | 无 |

### P1 - 异常分支（必测）

| ID | 场景 | 前置 | 操作 | 期望 |
|----|------|------|------|------|
| P1-01 | 无可处理的负载均衡 | 拦截或预置 `code=0` 且 `task_management_id=""` | 提交同步 | Toast「没有可处理的负载均衡」；不跳转；弹窗关闭 |
| P1-02 | 同账号地域任务进行中 | 拦截或预置 `code=2000002` | 提交同步 | Toast「该账号地域同步任务进行中」；弹窗不关或保持可重试；不当成已创建 |
| P1-03 | 其它接口错误 | 拦截 `code != 0` 且非 2000002，带 `message` | 提交同步 | Toast 展示接口 `message`；不当成任务已创建 |
| P1-04 | 未填地域 | 打开同步弹窗 | 不选地域直接确定 | 表单校验拦截，不发请求 |
| P1-05 | 同步任务不支持重执行 | 同步任务详情 | 看重执行入口 | 不可用（禁用或「暂不支持」），不会带出监听器/端口类 rerun 参数 |
| P1-06 | 列表按账号能搜到任务 | 有同步任务且 `account_ids` 含目标账号 | 账号条件选该账号后查询 | 请求 `account_ids` 的 op 为 `json_overlaps`（不是 `in`）；列表能出该任务 |
| P1-07 | 安全组同步文案未改 | 资源安全组列表 | 走安全组同步成功 | 仍 Toast「已同步成功」，不是 CLB 任务进度文案 |

| P0-01 | PASS | 用户确认自测：列表同步用 CLB 实际所属账号，Toast「同步任务已创建…」，回包非空 `task_management_id` |
