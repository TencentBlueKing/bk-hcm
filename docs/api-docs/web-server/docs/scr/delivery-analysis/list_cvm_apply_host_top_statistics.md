### 描述

- 该接口提供版本：v9.9.9+。
- 该接口所需权限：自研云管理-交付分析。
- 该接口功能描述：获取指定时间区间，业务申请主机数量的统计列表。

### URL

POST /api/v1/woa/task/apply/findmany/bizs_hosts/statistics

### 输入参数

| 参数名称      | 参数类型  | 必选 | 描述                              |
|--------------|---------|------|----------------------------------|
| start_time   | string  | 是   | 时间范围开始日期，格式如"2025-01-01" |
| end_time	   | string  | 是   | 时间范围结束日期，格式如"2025-01-31" |

### 调用示例

#### 获取详细信息请求参数示例

```json
{
  "start_time": "2025-01-01",
  "end_time": "2025-01-31"
}
```

### 响应示例

#### 返回结果示例

```json
{
  "result": true,
  "code": 0,
  "message": "success",
  "data": {
    "details": [
      {
        "bk_biz_id": 111,
        "host_count": 100,
        "order_count": 5,
      },
      {
        "bk_biz_id": 222,
        "host_count": 200,
        "order_count": 10,
      }
    ]
  }
}
```

### 响应参数说明

| 参数名称  | 参数类型 | 描述                                  |
|---------|---------|---------------------------------------|
| result  | bool    | 请求成功与否。true:请求成功；false请求失败 |
| code    | int     | 错误编码。 0表示success，>0表示失败错误   |
| message | string  | 请求失败返回的错误信息                   |
| data	  | object  | 响应数据                               |

#### data

| 参数名称         | 参数类型       | 描述                   |
|-----------------|--------------|------------------------|
| details	      | object array | 业务申请主机数量的统计列表 |

#### data.details[n]

| 参数名称              | 参数类型   | 描述            |
|---------------------|-----------|-----------------|
| bk_biz_id           | int       | 业务ID           |
| host_count          | int       | 成功申请的主机数量 |
| order_count         | int       | 成功申请的订单数量 |
